当前版本：**1.0.0-beta.1 · 重构版公开测试**。这是原0.4项目的重构版本，beta仍需真实酒馆与模型使用验收。

## 安装与升级

在SillyTavern扩展管理中安装或更新：

https://github.com/yanxu-orange/ST-Orange-Lantai-Benmo

更新前停止生成和总结，备份聊天、扩展设置与旧扩展。更新后完整刷新页面；不要同时启用正式仓库与测试仓库两份兰台。

旧0.4版成果与新版使用不同存储命名空间，**不会自动迁移**。本次仓库更新不删除宿主保存的旧数据，但不保证旧版成果在新版显示；要继续旧版请保留备份或切回归档标签`legacy/0.4.0-rc.1`。新重构版数据回退旧重构版本也应恢复对应备份，不混用新旧格式。

## 开始使用

从兰台设置中配置“连接方案”，在“任务API”为总结、自述与大纲、最新摘要／追踪／工坊、向量及重排分配方案。文本任务可使用酒馆主API，向量与重排使用各自专用接口。

事件记忆与古法总结整理历史，最新摘要与追踪维护当前状态，时间管理提供历法、日程及纪念日。可编辑各项生成要求和保存成果。BM25、向量、重排默认关闭，可按需开启；向量模型或浏览器改变后需重新处理向量记忆。雪山白鼬目前标为半成品主题。

更新检测与安装使用酒馆已有扩展管理功能；本插件不另建定时联网更新检测，也不在聊天或总结时自行替换代码。
