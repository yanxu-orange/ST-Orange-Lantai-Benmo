# 兰台本末

**兰台（LANTAI）** 是一款面向 SillyTavern 的剧情记忆与故事时间插件。

它把聊天中的重要事件整理为可以检查和编辑的长期记忆，并在后续对话中按关键词、故事时间和纪念日召回；同时提供故事日历、日程提醒和可自定义的聊天辅助功能。

> 当前版本：**v0.4.0 RC1**
>
> RC 表示发布候选版：核心流程已经完成真机验收，但仍可能根据后续使用反馈调整。

## 主要能力

- **事件记忆**：从聊天中整理重要事件，入库前可以检查和修改，之后也能继续编辑或删除。
- **记忆召回**：在后续对话中，根据关键词、故事时间和纪念日找回相关记忆。
- **故事时间与日历**：管理故事当前时间，支持现代日历、架空王朝历法和自定义历法。
- **日程与提醒**：安排一次性或每年重复的日程，并管理节日和纪念日提醒。
- **聊天辅助**：为正常聊天加入全局或当前聊天的自定义要求，也可以保存模型按要求生成的结果，或持续更新一份长期状态记录。

## 安装

需要可正常运行的 SillyTavern，以及 SillyTavern 所在环境可用的 Git。

1. 打开 SillyTavern 的 **扩展** 面板。
2. 选择 **安装扩展**。
3. 输入仓库地址：

   ```text
   https://github.com/yanxu-orange/lantai-benmo
   ```

4. 安装完成后刷新 SillyTavern。
5. 在扩展设置中启用兰台，再从扩展菜单中的 **兰台** 进入插件。

更新由 SillyTavern 的扩展管理功能完成；兰台本身不执行独立的版本检查。

## 开始使用

进入 **兰台 → 设置 → API 设置**，选择并配置一种来源：

- **插件 API**：使用单独保存的 URL、模型和 API Key。
- **SillyTavern 当前 API**：使用酒馆当前连接；必须由用户明确选择。

然后确认“在当前聊天中使用”已开启。兰台不会自动修改聊天原文；总结和召回只处理发送前的临时副本与插件自己的数据。

## 数据与隐私

兰台没有开发者运营的服务器，也不包含遥测或统计上报。需要 AI 的功能会把完成任务所需的提示词及所选聊天内容发送至用户选择的 API 服务。详细说明见 [PRIVACY.md](PRIVACY.md)。

升级、停用或卸载前，建议先按自己的 SillyTavern 备份方式保存重要聊天与设置。停用插件不等于删除数据。
