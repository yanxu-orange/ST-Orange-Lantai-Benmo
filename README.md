## 开始使用

从兰台设置中配置“连接方案”，在“任务API”为总结、自述与大纲、最新摘要／追踪／工坊、向量及重排分配方案。文本任务可使用酒馆主API，向量与重排使用各自专用接口。

事件记忆与古法总结整理历史，最新摘要与追踪维护当前状态，时间管理提供历法、日程及纪念日。可编辑各项生成要求和保存成果。BM25、向量、重排默认关闭，可按需开启；向量模型或浏览器改变后需重新处理向量记忆。雪山白鼬目前标为半成品主题。

更新检测与安装使用酒馆已有扩展管理功能；本插件不另建定时联网更新检测，也不在聊天或总结时自行替换代码。
